# PocketSmart AI – Your Smart Budget & Recommendation Assistant

## Project Overview
PocketSmart AI is a simple web-based personal budgeting assistant. It allows users to enter monthly income and expenses, calculates total spending and remaining balance, summarizes spending categories, and provides a rule-based smart recommendation.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Main Features
1. Monthly income entry
2. Expense entry by category
3. Total expense calculation
4. Remaining balance calculation
5. Category-wise spending summary
6. Smart budget recommendation

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open Terminal.
4. Run: `pip install -r requirements.txt`
5. Run: `python app.py`
6. Open the URL shown in the terminal, usually `http://127.0.0.1:5000/`.

## Note
The recommendation engine in this beginner version uses transparent rule-based logic based on income and spending percentage. It can later be extended with a machine-learning model.
